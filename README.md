 🌍 Clustering Global Development Categorization

 📌 Project Name
**Clustering Global Development Categorization**

 📖 Description

A **Clustering Global Development** project developed using **Python** and **Machine Learning** to group more than **190 countries** based on socio-economic and development indicators. The project applies data preprocessing, feature scaling, and multiple clustering algorithms to identify countries with similar development patterns. Different clustering techniques are evaluated using the **Silhouette Score**, and the best-performing model is selected for analysis. The final model is deployed using **Streamlit** for interactive visualization.

---

## 🚀 Features

* Clusters countries based on development indicators
* Data cleaning and preprocessing
* Outlier detection and treatment
* Feature scaling using StandardScaler
* Multiple clustering algorithms comparison
* Model evaluation using Silhouette Score
* PCA-based cluster visualization
* Interactive Streamlit web application
* Data-driven insights for global development analysis
